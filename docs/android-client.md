# Android 客户端：先配置一台，再复制经验

选择当前版本确实支持 Hysteria 2、规则分流和证书验证的 Android 客户端，例如 Hiddify 或其他兼容客户端。不同客户端的配置格式不通用；以所选应用当前官方说明和手机上的实际菜单为准，不把 Mihomo YAML 原样塞给任意应用。

1. 由本人安装应用并授权 Android VPN。执行 Agent 在私密配置中填写本次入口、端口、认证信息与正确的 TLS 名称；不关闭证书校验。先把一条指定域名设为家宽 HY2，其余设为直连。只有用户明确要求的目标进入海外规则。
2. 在家庭外网络测试真实网页、规则命中、DNS、服务端认证与双向流量；分别验证指定域名的家宽出口和直连域名的当前网络出口。再测试锁屏恢复、网络切换、断开重连和主机重启。
3. 如果执行 Agent 运行在电脑上且手机在手边，可由本人开启开发者选项、USB 调试并在手机上批准这台电脑的首次授权；随后使用 [scrcpy 官方项目](https://github.com/Genymobile/scrcpy)镜像手机，让 Agent 在授权范围内协助逐项设置。USB 调试只是操作通道，不代表客户端已安装或配置已导入。安装付费应用、应用商店登录和首次授权由本人完成。结束后撤销不再需要的 USB 调试授权。

若无公网入口，Android 上 Tailscale 私网 HY2 是否能与规则客户端并行，取决于应用和系统 VPN 实现。必须在该手机上实测，不能从 Mac 成功推断 Android 成功。并行不通时，可单独用已验收的 Tailscale Exit Node 整机保底；这不满足按域名分流。
