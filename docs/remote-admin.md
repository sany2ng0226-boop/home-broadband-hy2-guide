# 离境前先验收救援通道

本页解决的是“回国后还能修家里的主机吗”。远程管理、整机出口、HY2 分流是不同功能。按实际设备实现，至少留出几天观察和重启测试。

1. 在常开主机与管理用电脑安装 Tailscale，由本人登录同一个 Tailnet 并完成 MFA。离开家庭 Wi-Fi 后，验证设备互相可达。检查常开主机的**设备密钥到期时间**；若本人同意让受信任的无人值守主机长期保持连接，可在 Tailscale 管理后台对该设备关闭到期。默认期限可能是 180 天，但以实际 Tailnet 设置和该设备显示为准。定期审查设备访问权。参照 [官方密钥到期说明](https://tailscale.com/docs/features/access-control/key-expiry)。
2. macOS 主机如需命令行管理，由本人在“系统设置 → 通用 → 共享”开启“远程登录”，限定获授权的本机账户；在发起连接的电脑生成专用 SSH 密钥，只把**公钥**放进主机对应账户的 `authorized_keys`。通过主机 Tailnet 地址进行一次真实的远程登录和只读命令；不为 SSH 开公网端口。密钥私钥不发给 Agent 聊天窗口。若需要只允许转发的密钥，另设权限受限的凭据，不与管理密钥混用。Windows 则按实际版本配置受授权的远程管理方式并验证。
3. 图形远控是第二种操作入口。若本人使用 UU 远程，在家中主机与控制端完成安装、登录和无人值守授权，记录恢复方式；从家庭外网络真的连入一次并操作一项无风险设置。其连接可能直连或中继，不能把“已登录”当成“网络穿透直连已验证”。也可选择本人已有且受信任的图形远控工具。不要在仓库公开设备码、临时口令或截图。
4. 确认常开主机的睡眠、自动启动、断电恢复和加密磁盘解锁条件。目标是“人在外面时能恢复”，不只是当前屏幕保持亮着。Mac 的 FileVault 冷启动可能仍需现场解锁；不要为追求自动恢复擅自关闭加密。离境前做一次重启和一次断网/换网后的远程登录测试，并记录需要在场协助的限制。

**通过标准：**家庭外网络能经 Tailscale 真正进入命令行，且图形远控若被列为保底也能真正进入桌面；重启后再次成功。只有 Tailnet 设备显示在线、能 ping、或图形远控显示“已安装”都不算通过。

使用 HY2 规则分流时，不让 Tailscale Exit Node 与规则客户端同时接管整机默认路由。切换到 [Exit Node 整机保底](exit-node.md)前先关闭客户端的整机 VPN/TUN，切回前先取消 Exit Node；每种模式单独验收。
