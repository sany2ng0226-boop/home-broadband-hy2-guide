# HY2 验收、回国前检查与撤销

本页适用于 HY2 分流；整机出口采用 [Exit Node 页](exit-node.md)的验收，不要求域名规则命中或未指定网站 DIRECT。

部署结果必须由**真实请求**证明。服务进程在线、测速显示延迟和路由器页面出现映射，只能证明各自的一小段状态。

## 最小验收记录

| 测试 | 操作 | 通过证据 |
| --- | --- | --- |
| 管理保底 | 主力设备离开家庭 Wi-Fi，经 Tailscale 登录或管理主机 | 登录成功；管理会话可执行一次只读检查 |
| 本地服务 | 检查主机 HY2 进程、监听、TLS 和认证 | 新实例在选定 UDP 端口监听；无启动错误 |
| 海外规则 | 在家庭外网络访问一条用户指定域名 | 客户端规则命中 HY2；服务端有认证与双向数据；出口与家宽一致 |
| 直连规则 | 同一外部网络访问一条未指定域名 | 规则命中 DIRECT；没有对应 HY2 转发；出口仍是设备当前网络 |
| 内网隔离 | 用专门的无敏感测试目标验证 ACL | localhost/LAN/Tailnet 目标被拒绝，公网目标仍可用；不扫描家庭设备 |
| 持续与重连 | 连续使用至少 20 分钟，断开再重连，并切换一次网络 | 真实页面持续加载，重连后恢复；记下失败窗口和日志时间 |
| 重启恢复 | 主机重启后重新连接 | 服务自动启动、远程管理仍能使用、真实页面重新加载 |

若此前有间歇性故障，应把观察时间延长到至少覆盖一个已知复发周期；20 分钟只是在没有历史数据时的探索性起点，不构成长期稳定承诺。出口地址、位置、密码与日志在可分享的记录中脱敏。

核对出口时，先在家中主机记录 IPv4/IPv6 出口基线；用临时、精确的测试域名规则分别验证 HY2 与 DIRECT，再恢复规则。普通 IP 查询站若未加入 HY2 规则，默认 DIRECT 的结果不能证明 HY2 出口。网站自身没有显示出口时，用规则命中和服务端请求证据验证该网站；不要把另一条直连请求的 IP 混作它的出口。双栈网络分别记录地址族，不能要求 IPv6 地址与 IPv4 地址字面相同。

## 中国侧测试是额外证据

在海外本地无法证明中国境内运营商的 UDP 路径和晚高峰表现。若用户有愿意协助的中国测试者或获授权设备，执行 Agent 给用户一份短步骤：由用户决定如何安全提供测试配置，记录中国本地 SIM/宽带、直连出口与时段（境外 SIM 漫游不代表本地运营商），打开指定网页并保持数分钟，断开重连一次，回报结果；若凭据曾分享给他人，测试后轮换。Agent 不自行联系他人。若没有测试端，部署继续完成，报告注明“中国侧未验证”，回国后再补测。

单次失败也不能直接定位到防火墙。记录客户端网络、请求时间、是否完成认证、服务端对应日志，并用另一网络对照。`no recent network activity` 单独出现不等于实际页面失败。

## 交付前做回退演练

保留此次新增服务、启动项、配置路径、证书/凭据存放位置、主机地址保留及路由器映射的**私密清单**。回退顺序：在客户端关闭本次配置；停用本次新增服务和启动项；删除仅属于本次的路由器映射与 DHCP 保留（如果原来没有）；恢复改动前防火墙状态；最后验证旧网络与 Tailscale 管理仍可用。不得删除其他服务的规则或密钥。

最终可分享报告只写脱敏拓扑、端口角色、每项验证状态、剩余风险和回退方法，不附真实凭据。
