# 优先路径：HY2 走 Tailscale 私网

适用：主力设备能同时维持 Tailscale 连接和一个按规则分流的 HY2 客户端。两个设备都在同一个获授权的 Tailnet 内，且实测不发生路由回环。此路径不要求公网 IP、路由器登录或端口映射。

```text
主力设备规则客户端 ─HY2/UDP→ Tailscale 私网地址 ─→ 家中常开主机 HY2
         └─DIRECT────────────────────────────────→ 当前网络
```

1. 在两端安装/登录 Tailscale，读出主机 Tailnet 地址；关闭 Exit Node。从家庭外网络验证主力设备能管理主机，而不只是看到设备在线。
2. 在主机检查已有 UDP 监听，选一个本次专用内部端口。按 [服务端示例](../examples/server.example.yaml)生成仓库外的真实文件；服务端监听应限制在 Tailnet 可达的地址或以主机防火墙限制来源，不因私网部署而对整个局域网无差别开放。生成独立强随机密码和可验证的 TLS 证书。
3. 在客户端将 HY2 服务器地址设为主机 Tailnet 地址，TLS 名称仍须与证书匹配；若使用私有 CA，按所选客户端能力导入 CA 并验证。绝不以关闭证书验证代替信任配置。
4. 先用不接管整机的客户端代理模式，按指定域名走 HY2、其余 DIRECT。若系统代理不覆盖目标应用，再考虑 TUN，并检查 Tailnet 地址没有被重新代理到 HY2 自身。不要开启 Exit Node。
5. 离开家庭 Wi-Fi 后完成真实网页、规则命中、服务端认证和持续使用测试。若平台限制导致不能同时连接，或异网实测失败，记录结果后转 [公网路径](home-nat.md)。

这条路径减少家用路由器操作，但增加了客户端对 Tailnet 的依赖；它不是中国网络质量的证明。
