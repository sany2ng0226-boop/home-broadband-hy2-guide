# 最短路径：临时把整台设备切到家宽

如果目标只是短期用海外家庭出口，先评估 Tailscale Exit Node。它不需要 HY2 或家用路由器端口映射，但需要两端登录、常开主机、管理权限和实际网络测试。它使用 Tailscale 的连接路径；直连不成功时可能经中继，速度要实测。

1. 由本人在两端安装并登录 Tailscale；家中主机需要可以持续运行。先检查原来的 VPN/代理，保存恢复方法。
2. 按 [官方 Exit Node 指南](https://tailscale.com/docs/features/exit-nodes)让常开主机发布 Exit Node。不同系统的转发要求不同，Linux 按文档配置 IP 转发；在管理后台批准此设备，并检查访问策略允许本次客户端使用。确认主机仍正常联网。
3. 客户端先关闭其他会接管整机的代理/VPN，再选这台 Exit Node。只在确有需要时启用访问客户端所在局域网的选项。iPhone 使用 Tailscale 自身的 VPN，此时不运行 Shadowrocket 隧道。
4. 在家庭外网络比较启用前后的出口，确认启用后匹配家庭出口；分别测试目标网站、重连和主机重启。切为不使用 Exit Node 后，确认恢复当前网络出口。海外通过不代表中国通过，回国后仍需本地 SIM/宽带复测。

报告只写这条 Exit Node 路径的实测状态；没有 HY2 服务就不要写“HY2 部署成功”。如果整机切换已满足需要，到这里结束。只有需要指定域名走家宽、其他网站直连，才继续 [HY2 Agent 指令](agent-deploy.md)。

撤销：客户端取消 Exit Node；停用此次主机的出口发布和后台批准；恢复仅为这次新增的转发配置。若 Tailscale 同时承担原有远程管理，不卸载或停掉它。家庭主机的睡眠、停电、解锁和带宽限制同样适用，见 [风险与限制](risks.md)。
