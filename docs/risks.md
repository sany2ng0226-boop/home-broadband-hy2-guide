# 风险与限制

本指南只用于自己拥有或获得明确授权的网络。开始前，让家宽持有人理解这台主机将替设备访问互联网，并核对所在地要求、宽带合同和目标服务规则。不要把自用配置直接扩成公开代理或收费服务。

## “住宅出口”不等于“纯净保证”

方案改变的是目标网站看到的网络出口，不会抹掉账户历史、设备特征或网站自身判断。家庭 IP 可能变化、被共享或有历史信誉；地理识别、可用服务和风控结果不能保证。它也不提供匿名：经代理的请求会从这条家宽发出。

## 凭据泄露会牵连家庭网络

认证密码、导入链接和二维码都视为密码。公开截图只保留脱敏状态，不展示节点详情、家中地址、路由器入口、证书私钥或原始日志。若泄露，立即轮换凭据并重新验收；删除消息或工作区文件无法撤回旧副本。

服务端 ACL 默认拒绝内网目标；还应限制服务账户权限并维护本家庭公网/IPv6 地址的禁止回访规则。ACL 降低凭据被滥用后的影响，不能替代系统更新、防火墙和家庭网络隔离。只开放必需的 HY2 UDP 入站，不开 DMZ，不为远程排障顺手暴露路由器后台或 SSH。

## 它不是长期在线承诺

家庭上传速度、跨境链路和中继路径都会影响体验。主机睡眠、停电、证书到期、地址变化或路由器重启，都可能导致失联。离境前必须验证重启与恢复；FileVault 等启动解锁要求可能需要本人或现场协助，单有开机启动项不保证无人值守恢复。

## 国内能否用，要在国内验证

海外蜂窝测试能证明家庭外连接，不证明中国当地运营商、时段和 UDP 路径可用。境外 SIM 在中国漫游也可能从境外归属地出网。回国后用实际会使用的中国本地网络测试，并保留其他联网方式；一次成功或一次失败都不能概括长期表现。

## 分流与 DNS 要单独核对

规则只覆盖配置中命中的请求；同一应用可能使用多组域名，系统代理也可能被部分应用忽略。DNS、IPv4/IPv6、浏览器隐私中继或其他 VPN 会影响观察结果。逐个验证需要使用的应用与地址族，不把“打开一个 IP 查询页”写成“整台设备所有流量都走家宽”。日志中的域名和连接信息同样属于隐私。
