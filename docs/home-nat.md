# 家庭公网路径：从路由器到 HY2 主机

先只读检查本页的 WAN、上游 NAT 和已有规则，再决定入口。若公网 UDP 可达，可为单台设备建立最小映射；无可用公网入口时转 [私网路径](private-path.md)评估。本页不假设任何路由器品牌、管理密码、现成公网 IP 或现成端口。

```text
家庭外设备 ── 公网 UDP 外部端口 ── 家用路由器 ── 局域网主机 UDP 内部端口 ── 家宽出站
```

## 1. 找到路由器管理入口并判断 WAN

在连接家庭 Wi-Fi 的电脑上读取“默认网关”地址；在本地浏览器打开这个地址，使用**路由器管理员**凭据登录。Wi-Fi 密码不一定是管理密码。若默认网关只是第二层路由器或 AP，沿实际连线查上游设备的 WAN，不要把局域网地址当公网入口。

先截图或记录**脱敏的**现有 WAN、DHCP 保留和端口转发条目。再从家中主机调用一个外部地址查询服务，读取同一地址族的出口 IP。WAN 落在 `10/8`、`172.16/12`、`192.168/16` 或 `100.64/10` 等非公网范围，或与外部查询明显不同，说明可能有运营商 NAT 或上游设备；继续查上游，不能靠本路由器一条转发解决。WAN 与出口一致只是公网候选，仍须从家庭外做 UDP 实测。若走 IPv6，分别检查主机的全球单播地址、入站防火墙和客户端网络是否支持 IPv6；不要把 IPv6 可用自动等同于 IPv4 可用。

若找不到路由器入口或管理员权限，停在此步，把网关、设备标识及所需的最小操作告诉用户；不要猜密码或重置路由器。

## 2. 固定目标主机与选择端口

在路由器 DHCP 静态分配/地址保留页面，按常开主机的网卡标识保存固定局域网 IP；读回后验证主机网络和远程管理仍正常。若已有保留项，先核对而非覆盖。

检查主机的 UDP 监听、路由器已有转发和系统服务，选未占用的**外部 UDP 端口**与**内部 UDP 监听端口**。两者可以相同，也可以不同；它们都是端口号，不是设备地址。记录所选端口的角色和冲突检查结果。不要使用此仓库、截图、教程或旧生产实例给出的数值作为默认值。端口外观不能保证更稳定或更难被针对。

## 3. 先让服务本地监听，再做一条映射

按 [官方服务端配置](https://v2.hysteria.network/docs/getting-started/Server/)在主机安装独立 HY2 服务，以新密码、可验证的证书和本次内部 UDP 端口启动。确认进程、日志与 UDP 监听存在。若系统防火墙阻挡该入站端口，只放行本次服务和协议。

在路由器“端口转发/虚拟服务器”中只新增一条：协议 **UDP**、外部端口为本次选择值、目标 IP 为刚保留的主机地址、内部端口为实际监听值。保存并重新打开页面读回。不要开 DMZ、不要附带 TCP 或其他端口、不要改旧规则。优先手动映射；若只能用 UPnP，先向用户说明权限和租期并取得同意，记录规则归属与续租方式。

## 4. 从家庭外确认

让主力设备离开家庭 Wi-Fi，使用蜂窝或另一条独立网络进行**真实 HY2 认证和网页请求**；对齐客户端与服务端的时间、认证和双向数据。仅看端口检测网站、路由器显示“生效”或在同一 LAN 内连接均不算验收。若无法到达，分段检查外网 UDP 是否到路由器、路由器是否转给主机、主机是否回复；不要直接认定是防火墙。

若公网地址会变，离境前配置并异网验证 DDNS。使用手动静态映射时没有 UPnP 租约要续；只有选用有租期映射时才需要续租机制。

## 不通时的真实选择

- 有可达的 IPv6，且主力设备所在网络支持：可评估 IPv6 直接入站，并单独验证。
- 私网 HY2 曾成功：回到私网路径。
- 无可达入口：记录证据，向用户提出中转或其他架构选择；涉及新费用、第三方账号或架构改变时等用户决定。不要把 Tailscale Exit Node 的整机出口说成已完成域名分流。
