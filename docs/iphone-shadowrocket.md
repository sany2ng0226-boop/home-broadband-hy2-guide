# iPhone 客户端：Shadowrocket 单设备分流

本页针对一台 iPhone。**优先按公网 HY2 路径准备服务端**：普通 iOS 使用中，同一时间只运行一条设备级 VPN 隧道，不能依赖 Tailscale 与 Shadowrocket 双开来访问 Tailnet 地址。Tailscale 仍可单独打开用于远程管理或 Exit Node 保底，使用 Shadowrocket 前按实际设备状态切换。

## 部署前确认

- iPhone 上已安装兼容 Hysteria 2 的 Shadowrocket 版本，用户授权导入和启用 VPN。
- 服务端已按 [家庭公网路径](home-nat.md)从家庭外网络验证 UDP 可达。
- 有与连接名称匹配、iPhone 能正常验证的 TLS 证书。若客户端无法验证私有 CA，改用受信任证书；不勾选“不安全/跳过证书验证”。
- 用户已给出需要走海外出口的网站；未列入的站点按 DIRECT 处理。

## 在手机上配置

1. 在 Shadowrocket 中**新建** Hysteria 2 节点，填本次公网入口、外部 UDP 端口、全新认证密码、证书名称。不要导入旧订阅或复用真实生产配置。字段名称以当前应用版本为准，添加后读回逐项核对。
2. 建一份独立的规则配置：用户指定的域名或域名后缀指向这个 HY2 节点，其余匹配 DIRECT。选“规则”模式，确认所选节点与规则配置匹配。一个服务需要多个域名时，从连接日志补齐，不凭服务名称猜整套域名。
3. 先直接用蜂窝或另一条家庭外网络验证节点认证；不要让家中路由器是否支持 NAT 回环成为前提。若先做家中 Wi-Fi 基线，那一项仅供对照。蜂窝测试时在控制中心暂时断开当前 Wi-Fi，确认实际使用蜂窝数据；不要在“设置”中关闭 Wi-Fi 模块，以免断开 iPhone 镜像。打开一条指定网站、一条未指定网站，核对 Shadowrocket 的实际规则命中、出口和服务端双向数据。再测试锁屏后恢复、断开重连和 Wi-Fi/蜂窝切换。
4. 若另行配置并验收了 Tailscale Exit Node，切换保底时先关闭 Shadowrocket VPN，再打开 Tailscale 并选择已验证的家中节点；切回 HY2 前先取消 Exit Node 并断开 Tailscale VPN，再启用 Shadowrocket。两种模式各自实测，不能只看开关状态。

若执行 Agent 无法操作 iPhone，应给用户逐屏的最小操作指引，等用户完成导入与蜂窝实测并返回结果后才记录“通过”。含密码的导入链接或二维码只在用户授权的私密渠道展示，不放入截图、仓库或公开报告。

## 让 Agent 通过 iPhone 镜像协助

有兼容 Mac 时，可使用 Apple 的 [iPhone 镜像](https://support.apple.com/en-us/120421)：Mac 需 macOS 15 或更高且配备 Apple 芯片或 T2，iPhone 需 iOS 18 或更高；两端同一 Apple 账户、开启双重认证、Wi-Fi 和蓝牙，iPhone 锁定并放在 Mac 附近。本人完成首次配对和授权；实际地区可用性以 Apple 当前说明为准。该功能不能控制远在海外、未配对的手机。

macOS 27 或更高可在镜像窗口按 `Command-4` 打开控制中心，暂时断开当前 Wi-Fi 后测试蜂窝；[控制中心的断开与设置中关闭 Wi-Fi 不同](https://support.apple.com/en-us/102412)。旧版无法从镜像完成这一步时，由本人手持操作后重新锁屏。每轮确认没有自动连回 Wi-Fi，也没有经 Mac 热点出网；镜像若受 VPN 影响就改手持测试，不为镜像关闭必要的安全校验。

**测试位置分两次：**出国/回国行程前，在海外用家庭外网络完成安装、认证、重连和重启测试，出问题还来得及处理主机；到中国后再用中国本地 SIM 或宽带验证真实网页及晚高峰。境外 SIM 的国际漫游可能回归属地出网，不代表中国本地网络。镜像只方便操作，并不改变测试发生的位置。
